# Production Failure Modes

This document analyzes the top 3 failure modes observed during the evaluation of the PariShiksha RAG pipeline.

## 1. Retrieval Miss
Description of cases where the correct context was not retrieved.

## 2. Context Fragmentation
Analysis of issues caused by splitting examples or solutions across chunks.

## 3. Plausible Hallucinations / Refusal Failures
Cases where the model either answered OOD questions or refused valid textbook questions.
